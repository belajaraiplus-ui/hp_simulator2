# Pedagogy Scoring Rubric (Phase 3)

Reasoning score is `0..100` using weighted components:

- Evidence completeness: **30%**
- Sequence quality: **25%**
- Risk handling: **25%**
- Hypothesis revision quality: **20%**

Status bands:
- `needs_guidance` for score < 60
- `acceptable` for score 60..79
- `trainer_ready` for score >= 80

## Trainer SOP
1. Review timeline (tick-ordered audit entries).
2. Confirm risky/damage/misleading consequences are causal.
3. Inspect evidence graph links (`supports`, `contradicts`, `untested_assumption`, `risk_introduced`).
4. Read postmortem recommendations + blind spots before grading technician behavior.
